# 整体界面缩放设计

[开发文档](development.md#窗口布局) · [中文 README](../README.zh-CN.md) · [渲染排障](troubleshooting.md)

## 目标与最终交互

缩放统一作用于侧栏、主面板、文字、图标及控件；原生窗口的尺寸、定位和可见区域随之拟合。入口保留在外观设置中，便于发现和理解。

| 项目 | 约定 |
| --- | --- |
| 范围 | 75%–150%，步长 5%，默认 100% |
| 控件 | 细轨道与显示实际百分比的圆角滑块，不显示左右端点或额外说明 |
| 拖动 | 只更新滑块位置和百分比，不改变整个界面的尺寸 |
| 松手 | 应用目标比例并保存；捕获指针以支持移出滑块后松手 |
| 键盘 | 方向键、Home、End、PageUp、PageDown 在松键后应用；失焦时提交尚未应用的值 |
| 取消 | 指针取消或意外失去捕获时，恢复已应用比例 |
| Reset | 立即选择并应用 100%，无需松手提交；视觉过渡沿用普通缩放流程 |
| 启动恢复 | 直接恢复保存的比例，不播放缩放动画 |
| 减少动态效果 | 系统启用 `prefers-reduced-motion: reduce` 时直接应用，不播放动画 |

拖动值与实际应用值分开管理。拖动期间窗口保持稳定，避免滑块随整个界面的尺寸和位置变化，影响指针操作。

## 缩放与过渡流程

实际布局使用 `.app-shell` 的 CSS `zoom`。比例只在提交时修改一次，过渡期间不逐帧修改 `zoom`。

1. 将目标比例写入 `--interface-scale`，发出 `interface-scale-changed`，请求窗口拟合。
2. 测量未加动画变换的目标宽度，缓存为 `data-scale-layout-width`。缩小时，通过 `data-scale-fit-ratio` 预留较大端点的显示空间，避免旧尺寸画面被提前裁掉。
3. 在 `.window-body` 上创建 `transform: scale(旧比例 / 新比例)` 到 `scale(1)` 的动画，先暂停在起点，保留原有视觉尺寸。
4. 窗口拟合完成后发出 `interface-scale-fitted`，按实际展开方向更新动画原点，再开始播放。未收到通知时，200 毫秒后回退启动，避免一直停在起点。
5. 动画持续 180 毫秒，缓动为 `cubic-bezier(0.22, 1, 0.36, 1)`。向左展开时以右上角为原点，向右展开时以左上角为原点。
6. 动画结束后移除临时测量数据和动画，重新拟合最终可见区域。

200 毫秒回退等待与 180 毫秒动画时长是不同参数。原生几何操作完成不代表 WebView2 已呈现该帧，不能将拟合通知视为逐帧渲染确认。

新比例通过现有设置存储保存，键为 `quotapeek-interface-scale`，写入延迟 200 毫秒。只保存最终选择的比例，不保存动画变换或预留区域。恢复时将异常值回退为 100%，有效值按步长取整并限制在范围内。

## 原生窗口稳定性

界面比例与显示器 DPI 分开计算：CSS 布局经界面缩放后，再按窗口 DPI 转成物理尺寸；显示器工作区原点保持物理坐标。内容超过高度上限时在面板内滚动，窗口靠近底部时校正纵向位置。

Windows 保留在当前拟合流程中使用过的较大原生绘制宽度，并按当前显示器工作区限制保留宽度；高度沿用稳定视口策略。缩小时收回可见裁剪区域，不同时缩小 WebView2 绘制表面，减少旧画面短暂出现的机会。裁掉的区域既不显示，也不接收鼠标。

动画预留空间只参与尺寸和裁剪计算，不放大侧栏宽度、窗口内边距等定位参数。否则在收回预留空间时，侧栏锚点也会改变，造成过渡结束时再跳动一次。

拟合仍通过单一路径串行提交。拖动窗口期间暂停拟合，松开后恢复；来源位置或几何版本已失效的请求不能覆盖新位置。

## 已排除的方案

| 方案 | 本次观察到的问题 | 保留的处理 |
| --- | --- | --- |
| 拖动时实时缩放整个界面 | 窗口、布局和滑块一起变化，拖动卡顿且手感不稳定 | 拖动预览数值，松手后应用 |
| 每帧修改 `zoom` 以平滑过渡 | 每帧重算布局并触发原生拟合，出现卡帧 | 一次修改布局比例，以 `transform` 做视觉过渡 |
| 动画与原生拟合同时启动 | 窗口定位与动画抢时序，画面短暂跳变 | 等拟合通知后播放动画 |
| 动画结束后缩小原生表面 | 可能出现旧帧或再次位移 | 保留较大表面，只收回可见区域；预留尺寸不改变定位锚点 |

移动设置入口本身无法解决这些渲染问题。当前保留外观设置入口；将来如需右键快捷操作，可复用同一套提交、保存和过渡逻辑。
